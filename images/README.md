# Images

Drop files here with these exact names and the page picks them up automatically.
Until a file exists, its slot falls back to a gradient panel with the title on it,
so the page always looks finished.

## Unreal screenshots

Landscape, 1200px wide or more. Student work from past semesters is ideal.

| File | Suggested content |
|---|---|
| `images/unreal/01.jpg` | A blockout or work-in-progress scene |
| `images/unreal/02.jpg` | Lighting study |
| `images/unreal/03.jpg` | A finished render or 8-second loop frame |

If you use student work, get the student's permission and credit them —
edit the caption under each image in `index.html`.
